A host is connected to a shared medium that uses CSMA/CA (without RTS/CTS) as its MAC protocol. Suppose the host has sent a frame and received an ACK. What will it do next? Freeze the backoff timer until the transmission ends, then resume the backoff when the channel is idle again for one DIFS. The frame transmission is complete, so the host does not need to do anything else. Give up. Wait for the end of the current transmission plus one DIFS, then begin the random backoff procedure.

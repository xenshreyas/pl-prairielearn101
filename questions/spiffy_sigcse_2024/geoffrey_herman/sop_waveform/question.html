Waveform Viewer Tutorial Workspace Waveform Viewers ========================== If you want to verify that your circuit is working correctly or you want to debug your circuit, it can be helpful to see what your circuit is doing in a timing diagram. You can use the `waveform viewer` to do this. Create your vcd file -------------------- After you've written your Verilog code (e.g., `circuit.v` or `sc2_block.v` ), you will need to create a corresponding Verilog test bench (e.g., `circuit_tb.v` or `sc2_block_tb.v` ). Once you have run your executable, you should have a .vcd file. You may need to press the `Refresh Explorer` button after compiling to see your .vcd file. .vcd Viewer ----------- If you click twice on the `.vcd` file in the file navigator, it will open the waveform viewer. This viewer is currently limited to letting you view just 8 signals at a time. If the name of the module in your test bench was `reg_writer_test`, you might see something like the following. If you click the "Add Signals" button, you will see a list of modules and signals. Notice the word `reg_writer_test` in the far-left panel (modules panel) of the viewer. The viewer shows a hierarchy of modules with each indented module being used by the module above it ( `reg_writer_test` comprises `rf` and `writer` modules). If you click on a module, the panel to the right (signals) will show the signals available to inspect in that module (e.g., `regnum` or `done` ). You can add signals to view if you double-click a signal or you can use ctrl+click to select several signals before pressing "Add signals." After you add some signals your waveform viewer might look the following. A time cursor starts at 0s. You can move the time cursor by clicking anywhere on the timeline. If you use the magnification tools in the Zoom controls, the viewer will zoom in on the cursor. If you press the four arrows pointing out, it will expand the waveform to exactly fit the screen. If you click on a signal, you can change the radix that is used to display the signal (i.e., hexadecimal, binary, or decimal). You can also remove a selected signal by using the trash can icon. Since you can view only 8 signals at a time, you may need to remove a signal to view an extra one. If you see an `x` in the waveform viewer, that means that the signal's value could not be determined based on the module and test bench. If you see a `z` in the waveform viewer, that means that the signal was not has not been defined by the testbench. #### Finding Bugs with the Waveform Viewer In this question you will be given a `.vcd` file that can be used to view a waveform generated by some Verilog code.

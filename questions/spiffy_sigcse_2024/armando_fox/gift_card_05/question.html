Overview of CHIPS 8.5: Intro to RSpec ===================================== Your app manages online gift cards for a soon-to-be-major e-tailer.Customers can use the app to place orders using their cardbalance. The system under test (SUT) consists of two classes that model theGiftCard and the Customer. Your task is to write a test suite for certain behaviors of these classes. In each part of this exercise, you'll add tests for new behaviors ofthe gift card. You must complete each part with 100% credit beforeyou can move on to the next part, but you have an unlimited number ofsubmission attempts to do so and there is no penalty for multiplesubmissions. Some test cases will be very simple, whereasothers will make use of test doubles,DRYing out of preconditions, and other techniques.But keep in mind that in the end, every testcase follows the same pattern: 1. **Arrange** any preconditions that must be in place in order for this test case to exercise the desired specific behaviors in the SUT. 2. **Act** by stimulating the SUT to elicit the behavior 3. **Assert** that various postconditions are true after the SUT has been exercised.

In this question you will complete the implementation of a class used in a system to handle customer sales for a store. Assume the following class declaration for a class named `Product` : public class Product { private int id; private String name; private int price; public Product(int id, String name, int price) { this.id \= id; this.name \= name; this.price \= price; } public int getId() { return this.id; } public String getName() { return this.name; } public int getPrice() { return this.price; } public int getTotalPrice(int quantity) { return quantity \* this.price; } } Now implement a new class named `PromotionalProduct` that is similar to `Product`, but that has a special price for higher quantities. If the order quantity is larger than or equal to `promotionQuantity`, then the price per unit is `promotionPrice`, otherwise the regular price applies (for example, the product is priced at 50 dollars, but if you buy at least 10 items you only pay 45 dollars). Note that most of the functionality is already implemented, you only need to implement the `getTotalPrice` method.

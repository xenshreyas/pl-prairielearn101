The examples we've been working with have mostly been about analyzing existing data. We tend to follow a similar pattern each time: 1. Read data in from a file 2. Look for some characteristics/process the data 3. Plot the data to see trends, patterns, extremes, etc. MATLAB is also widely used to **simulate data**. When we simulate data, we also tend to follow a similar pattern each time: 1. Convert the math equations into a computer program 2. Create a starter set of data and use the computer program from step 1 to generate predicted data 3. Look for some things / process data / plot data to see trends, etc. Math equations tend to look something like this: $$y=sin(x)$$ We know that this equation is really saying: $y$ is equal to the sine of $x$ for all possible values of $x$, no matter how big or small or precise those numbers are. You might be able to type $$plot(sin)$$ into a graphing calculator and get a plot containing a sine wave because the graphing calculator knows that you probably mean: show me a plot of the values of the sine of $x$ vs. $x$ for all possible values of $x$, no matter how big or small or precise those numbers are. But if we type $$plot(sin)$$ into MATLAB, we get an error message because MATLAB doesn't know that we mean `sin` to really mean $sin(x)$ and $x$ to be a variable with all possible values of $x$. So MATLAB says, _"¯ \\ _(ツ)_ /¯ lol whatever"_ and gives us an error message. To run a simulation in MATLAB, we first need to create a _starter set of data_. In Homework 2, we created vectors and matrices, and we saw that range notation ( `start:step:last` ) was quite convenient for creating a starter set of data. In our earlier attempt to plot $sin(x)$, we noted that the plot function requires a set of ordered pairs, e.g. $(x\_1,y\_1)$, $(x\_2,y\_2)$, $(x\_3,y\_3)$, etc. We can generate these easily using vectorized code! Try simulating $z=x^2$ by typing `z=x .^ 2` into MatCrab!_ Now, that we have a set of data points for `x` and `y`, if we call `plot(x,y)`, we get a plot of `sin(x)` using these values of `x`. To create a smoother plot of a math function, just use more data points. To do this with range notation, decrease the step size from the default of 1 to a new value, 0.1: x \= 1:0.1:10; y \= sin(x); plot(x,y); Another useful way to create a starter set of data is with the `linspace` function. The `linspace` function provides an alternate way to create evenly spaced vectors of numbers.

You are hired by a bike sharing company that wants to use machine learning to better manage their bicycle inventory across the five stations in their network. They give you a spreadsheet of bicycle demand per hour for the last year, with 5000 rows and the following columns: * month (1 to 12) * hour (0 to 23) * weekend (0 for M, T, W, Th and 1 for Sat, Sun) * holiday (0 for non-holiday days, 1 for holidays) * temperature (in °C) * precipitation (in cm) * station index (0 to 4) * number of bikes checked out in that hour You decide to use a fully connected neural network with a single hidden layer. Your network will output a vector, with the predicted bike demand for each station. For example, if the output of the network is \[0, 3, 2, 1, 1\], this means that the expected demand is 0 bikes for station 0, 3 bikes for station 1, 2 bikes for station 2, 1 bike for station 3, and 1 bike for station 4. (Note: the station index column will not be a "feature" input to your model, since each output from the network includes a value for each station!) * * * How many input units will your network have? (Not including any bias unit.) * * * How many output units will your network have? * * * How many units will you use in the hidden layer? (Not including any bias unit.) * * * What activation function will you use at the hidden units? relu sigmoid tanh softmax linear * * * What activation function will you use at the output units? relu sigmoid tanh softmax linear

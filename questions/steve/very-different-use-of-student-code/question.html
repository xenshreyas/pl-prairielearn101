Imagine that we want to store data about a hedge maze. Because of the way you create the design, a path in the maze can either be a dead-end (no exit) or a split from whicheither two paths or three paths lead out. Also, everypoint (dead-end or split) has a plaque on it indicating the donor name who sponsored that part of the maze (just text). Information about the plaque must go _first_ in your data type's cases. Your task is to reorder the following words: > `String` `Split2` `data` `HedgeMaze` `String` `Split3` `HedgeMaze` `DeadEnd` `String` `|` `HedgeMaze` `HedgeMaze` `|` `HedgeMaze` `HedgeMaze` `=` in order to define an algebraic data type for this data. That is, you define the algebraic data type using only the words above to do so, but in whatever order you choose and with whatever spacing/indentation you choose.
